# ООО Логос-ВЛ - Лендинг юридической компании

Современный одностраничный сайт для юридической фирмы, специализирующейся на поддержке строительных организаций.

## Структура проекта

```
/course_rep-1/
├── index.html          # Главная страница
├── css/                # Стили сайта
│   ├── styles.css      # Основные стили
│   └── fonts.css       # Локальные шрифты
├── js/                 # JavaScript файлы
│   └── main.js         # Интерактивность сайта
├── images/             # Изображения
│   ├── hero-bg.jpg     # Фоновое изображение главной секции
│   └── about-office.jpg # Изображение офиса в секции "О компании"
├── fonts/              # Локальные шрифты
│   └── montserrat.woff2 # Шрифт Montserrat
├── robots.txt          # Инструкции для поисковых роботов
├── sitemap.xml         # Карта сайта
└── README.md           # Документация проекта
```

## Запуск проекта

1. Откройте файл `index.html` в веб-браузере
2. Или запустите локальный сервер:
   ```bash
   # Python 3
   python -m http.server 8000

   # Node.js (если установлен)
   npx serve .
   ```

## Разработка

Для внесения изменений:

1. **Стили**: редактируйте `css/styles.css`
2. **Шрифты**: обновите `css/fonts.css` и файлы в папке `fonts/`
3. **JavaScript**: модифицируйте `js/main.js`
4. **Изображения**: добавьте файлы в папку `images/`
